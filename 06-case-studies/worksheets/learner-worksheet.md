## القسم 2: هل هذه مشكلة وكيل أم محادث آلي؟ (ناتج 1)

| السؤال | نعم / لا | الدليل |
|---|---|---|
| هل تتطلب المهمة أكثر من خطوة (بحث، ثم تحليل، ثم إجراء)؟ | | |
| هل تحتاج إلى الاتصال بأنظمة داخلية (CRM، ERP، مستودع بيانات)؟ | | |
| هل الناتج المطلوب **إجراء** (إنشاء طلب، تحديث سجل، إرسال) لا مجرد **إجابة**؟ | | |
| هل يتخذ النظام قراراً ضمن صلاحية محددة دون الرجوع إلى إنسان؟ | | |
| هل يحتاج إلى التنسيق بين أكثر من مصدر بيانات؟ | | |
| هل يعرف متى يتوقف ويصعّد إلى إنسان؟ | | |

**الحكم.** إن كانت أغلب الإجابات «نعم» فالمشكلة مشكلة وكيل. إن كانت «لا» فقد يكفي محادث آلي أو أتمتة بقواعد، وهذا ليس عيباً: هو أرخص وأسلم. اكتب حكمك في جملتين.

**تمرين معايرة.** طبّق الجدول أولاً على [Suitor](../global/suitor.md) ثم على [Tamimi](../saudi/tamimi-markets-askbaba.md) قبل تطبيقه على منشأتك.

## القسم 4: اختيار فرصة واحدة (ناتج 3)

قيّم فرصتين أو ثلاثاً بـ[أداة تقييم الفرص](../../04-entrepreneur-toolkit/02-ai-opportunity-assessment.md). ثم أجب هنا:

- أي فرصة اخترت، وما الدليل على أعلى ثلاث درجات منحتها؟
- لماذا رفضت الأخريين؟ جملة لكل واحدة.
- ما الخطر الجديد الذي يدخله الوكيل ولم يكن موجوداً؟

## القسم 5: المقابلات (ناتج 4)

استخدم [قالب اكتشاف العملاء](../../04-entrepreneur-toolkit/03-customer-discovery.md). القاعدة: اسأل عمّا حدث، لا عمّا قد يحدث.

**أسئلة تكشف السلوك:**
- صف لي يوم أمس في العمل. ما أول شيء فعلته وما آخر شيء؟
- حدّثني عن آخر مرة احتجت فيها إلى هذه المعلومة. ماذا فعلت بالضبط؟ بمن اتصلت؟ كم انتظرت؟
- ماذا فعلت **بدل** الإجراء الرسمي حين تأخرت الإجابة؟
- كم مرة حدث هذا الشهر الماضي؟ ما أسوأ مرة؟
- أين تتعثر: في الوصول إلى البيانات، أم في فهمها، أم في تحويلها إلى إجراء؟
- ما الأدوات التي تستخدمها الآن؟ هل جرّبت حلاً من قبل؟ ماذا حدث؟

**أسئلة تجنّبها:**
- هل تحب أن يكون لديك وكيل ذكي؟
- هل ترى أن الذكاء الاصطناعي مهم؟
- كم ستدفع مقابل حل كهذا؟ (قبل أن تعرف كلفة المشكلة اليوم)

**مخرَج المقابلات.** خمس مقابلات على الأقل في الشريحة نفسها، إحداها مع صاحب الميزانية.

## القسم 6: أطروحة الفرصة (ناتج 5)

صفحة واحدة بالعربية:

1. **العنوان:** جملة تحدد المنشأة وسير العمل والأثر.
2. **المشكلة:** سير العمل الحالي، القيد، التكلفة بالأرقام ومصدر كل رقم.
3. **الدليل السلوكي:** ما رأيته في المقابلات. ليس «قالوا إنهم يريدون» بل «قالوا إنهم فعلوا كذا حين حدث كذا».
4. **لماذا وكيل لا محادث:** من جدول القسم 2.
5. **الحل:** ما يفعله الوكيل خطوة بخطوة، والأنظمة التي يتصل بها.
6. **ما يبقى للإنسان:** نقاط الموافقة وقائمة «لا تفعل أبداً».
7. **من يدفع وكيف:** المشتري، المستخدم، وأساس التسعير.
8. **قياس النجاح:** زمن الدورة، الأخطاء، تكلفة المهمة المنجزة، وخط الأساس قبل البدء.
9. **الافتراضات الثلاثة الأخطر:** ما الذي يبطل الأطروحة، وكيف تختبره بأقل تكلفة؟

**اختبار أخير.** اعرض الأطروحة على شخص من المنشأة. إن لم يتعرف على مشكلته في الفقرة الثانية، فارجع إلى القسم 5.
