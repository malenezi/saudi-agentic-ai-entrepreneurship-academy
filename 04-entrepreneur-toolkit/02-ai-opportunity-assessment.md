# تقييم فرص الوكلاء · AI Opportunity Assessment

Use this to compare candidate workflows and choose one. SME owners can run it on their own operations to find where an agent pays back first.

## الخطوة 1: اذكر المرشحين · Step 1: List candidates

List three to five workflows. Describe each as a verb and an object: "مطابقة الفواتير مع كشف الحساب", "الرد على استفسارات الحجز".

## الخطوة 2: قيّم كل مرشح · Step 2: Score each

Score 1 (low) to 5 (high). Be honest: the point is to choose, not to justify.

| المعيار · Criterion | ماذا تسأل · Ask yourself | الوزن · Weight | أ | ب | ج |
|---|---|---|---|---|---|

## الخطوة 3: فحص الإيقاف · Step 3: Stop checks

Any "yes" means redesign or drop the candidate, whatever its score.

| السؤال · Question | أ | ب | ج |
|---|---|---|---|
| هل خطأ واحد قد يسبب ضرراً جسيماً لشخص، ولا توجد مراجعة بشرية؟ · Could one error seriously harm a person, with no human review? | | | |
| هل العمل يتطلب ترخيصاً مهنياً لا نملكه (طبي، قانوني، مالي)؟ · Does the work need a professional licence we lack? | | | |
| هل يتطلب بيانات حساسة لا نستطيع معالجتها نظامياً الآن؟ · Does it need sensitive data we cannot lawfully process now? | | | |
| هل لا يوجد مالك واضح للقرار عند العميل؟ · Is there no clear decision-maker at the customer? | | | |

## الخطوة 4: هل هو وكيل أصلاً؟ · Step 4: Is it an agent at all?

| إذا كان العمل… · If the work is… | فالأنسب… · Then use… |
|---|---|
| خطوات ثابتة لا تتغير · Fixed steps that never vary | أتمتة عادية بلا نموذج لغوي · Plain automation, no language model |
| خطوات ثابتة مع نص يحتاج فهماً · Fixed steps with text that needs understanding | سير عمل فيه خطوة نموذج لغوي · A workflow with a model step |
| خطوات تتغير حسب الحالة وتحتاج قراراً واختيار أدوات · Steps that vary by case and need decisions and tool choice | وكيل · An agent |
| أدوار متخصصة متعددة وتسليم بينها · Several specialised roles with handoffs | أكثر من وكيل، بعد إثبات الحاجة · Multiple agents, once the need is proven |

Choose the simplest option that does the job. Simpler is cheaper, faster and fails less.
