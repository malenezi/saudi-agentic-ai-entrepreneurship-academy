# لوحة فكرة المشروع · Startup Idea Canvas

One page. Short, specific answers. If a box is empty, that is your next task.

**اسم المشروع · Working name:** ____________  **التاريخ · Date:** ____________  **الإصدار · Version:** ____

| | |
|---|---|
| **1. العميل · Customer** <br> من بالتحديد؟ القطاع، المدينة، حجم المنشأة، وظيفة الشخص. <br> Who exactly? Sector, city, business size, role. | |
| **2. المشكلة · Problem** <br> ما العمل المتكرر المؤلم؟ كم مرة يحدث وكم يكلّف؟ <br> Which repetitive, painful job? How often and at what cost? | |
| **3. الحل الحالي · Current way** <br> كيف يُنجز اليوم؟ موظف، جدول، برنامج، أو لا يُنجز. <br> How is it done today? A person, a spreadsheet, software, or not at all. | |
| **4. الدليل · Evidence** <br> ماذا رأيت أو سمعت من عملاء حقيقيين؟ كم مقابلة؟ <br> What have you seen or heard from real customers? How many interviews? | |
| **5. دور الوكيل · The agent's job** <br> ما الذي ينجزه الوكيل من البداية إلى النهاية؟ <br> What does the agent complete end to end? | |
| **6. دور الإنسان · The human's job** <br> ما الذي يبقى مع الموظف؟ ما الذي يحتاج موافقة؟ <br> What stays with a person? What needs approval? | |
| **7. القناة · Channel** <br> أين يلتقي العميل بالوكيل؟ واتساب، موقع، بريد، نظام داخلي. <br> Where does the customer meet the agent? | |
| **8. القيمة · Value** <br> ماذا يكسب العميل؟ وقت، مال، مبيعات، أخطاء أقل. بالأرقام إن أمكن. <br> What does the customer gain? In numbers where possible. | |
| **9. الإيراد · Revenue** <br> كيف ستتقاضى؟ لكل مهمة، اشتراك، نسبة من النتيجة. <br> How will you charge? | |
| **10. التكلفة · Cost** <br> ما تكلفة إنجاز مهمة واحدة تقريباً؟ <br> Rough cost to complete one task? | |
| **11. الميزة · Edge** <br> ما الذي تملكه ولا يمحوه إصدار نموذج جديد؟ <br> What do you own that a new model release cannot erase? | |
| **12. البيانات والأنظمة · Data and rules** <br> ما البيانات الشخصية المعنية؟ هل القطاع منظَّم؟ <br> Which personal data is involved? Is the sector regulated? | |
| **13. أكبر مجهول · Biggest unknown** <br> ما الافتراض الذي إن كان خاطئاً سقط المشروع؟ <br> Which assumption, if wrong, kills the idea? | |
| **14. الخطوة التالية · Next step** <br> ماذا ستفعل هذا الأسبوع لاختبار ذلك الافتراض؟ <br> What will you do this week to test it? | |
