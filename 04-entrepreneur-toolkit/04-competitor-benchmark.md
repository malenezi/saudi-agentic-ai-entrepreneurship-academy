## 3. اختبار «الغلاف الرقيق» · The thin-wrapper test

Answer honestly. If most answers are "nothing", deepen the product before selling it.

| لو أصدر مزوّد النموذج غداً ميزة عامة مشابهة، ما الذي يبقى لنا؟ · If a model provider shipped a similar generic feature tomorrow, what would we still have? | |
|---|---|
| معرفة عميقة بسير العمل والاستثناءات · Deep knowledge of the workflow and its exceptions | |
| تكاملات مع أنظمة محلية · Integrations with local systems | |
| بيانات خاصة ومجموعة تقييم من حالات حقيقية · Proprietary data and a test set of real cases | |
| ثقة وعلاقات وقناة توزيع · Trust, relationships and distribution | |
| امتثال وموقع بيانات يطلبه المشتري · Compliance and data location buyers require | |

## 4. قواعد البحث · Research rules

- جرّب المنتج المنافس بنفسك إن أمكن. · Try the competitor's product yourself where you can.
- اسأل العملاء ماذا يستخدمون ولماذا. · Ask customers what they use and why.
- لا تنقل ادعاءات تسويقية كحقائق. · Do not repeat marketing claims as facts.
- حدّث الجدول كل ثلاثة أشهر. · Refresh the table every three months.
