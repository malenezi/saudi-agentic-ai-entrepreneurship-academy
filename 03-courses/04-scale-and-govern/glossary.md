# مسرد المقرر 4 · Course 4 glossary

<div dir="rtl">

المصطلح الإنجليزي يُذكر عند أول ورود في الدروس مع مقابله العربي. ما ورد في مسارد المقررات [1](../01-opportunity/glossary.md) و[2](../02-build/glossary.md) و[3](../03-launch/glossary.md) لا يُعاد هنا.

## التشغيل

| English | العربية | المعنى في هذا المقرر |
|---|---|---|
| Agent-operated company | منشأة يشغّلها الوكلاء | منشأة وظائفها يؤديها وكلاء ويشرف عليها بشر |
| Operating architecture | معمارية التشغيل | الوكلاء والأدوار البشرية والأنظمة والتسليمات ونقاط الموافقة |
| Agent register | سجل الوكلاء | سطر لكل وكيل: مستواه ومالكه وأدواته وما لا يفعله |
| Agent level | مستوى الوكيل | تصنيف الأكاديمية من 1 إلى 4: يقدّم معلومات، يوصي، ينفّذ ما يُتراجع عنه، ينفّذ ما له أثر جوهري |
| Owner | المالك | إنسان مسمّى يُسأل عن وكيل أو قرار أو خطر |
| Shared context | السياق المشترك | ما يقرؤه أكثر من وكيل: سياق المنشأة، سجل العميل، حالة المهمة، الذاكرة |
| Task state | حالة المهمة | ما أُنجز وما ينتظر، بحقول يقرؤها الوكلاء المشاركون |
| Long-term memory | الذاكرة طويلة الأمد | ما يحتفظ به الوكيل بين المهام |
| Handoff | التسليم | انتقال العمل من وكيل إلى وكيل، أو من وكيل إلى إنسان |
| Approval point | نقطة الموافقة | تسليم إلى إنسان يقرر قبل أن يُنفَّذ الفعل |
| Consequential decision | القرار المؤثر | ما يحرّك مالاً، أو يُلزم المنشأة، أو يكشف بيانات، أو يغيّر صلاحية، أو لا يُتراجع عنه |

## المراقبة

| English | العربية | المعنى في هذا المقرر |
|---|---|---|
| Task / Run / Tool call | المهمة / التشغيل / استدعاء الأداة | ثلاث وحدات عدّ لا تُخلط |
| Escalation rate | نسبة التصعيد | المهام المحالة إلى إنسان من المهام النهائية |
| Time to resolution | زمن الإنجاز | من دخول المهمة إلى إغلاقها، ومنه انتظار الإنسان |
| Sampling | المراجعة بالعيّنة | قراءة إنسان لعيّنة عشوائية ولكل ما صُعِّد |
| Confidence interval | فترة الثقة | المدى المعقول للنسبة الحقيقية بالنظر إلى حجم العيّنة |
| Tracing | التتبع | تسجيل ما دخل وما استُدعي وما خرج وما تقرر لكل مهمة |
| Limit | حدّ الإيقاف | سقف يُفرض في التطبيق ولا يتجاوزه الوكيل |
| Alert threshold | عتبة التنبيه | قيمة إن عُبرت وصل تنبيه لإنسان مسمّى |
| Change control | ضبط التغيير | لا تغيير في النموذج أو التعليمات أو الأدوات قبل اختبار وتسجيل |
| Version pinning | تثبيت الإصدار | استدعاء إصدار محدد من النموذج، لا اسم عام يتغير |
| Regression test | اختبار الانحدار | إعادة مجموعة الاختبار كلها بعد تغيير |
| Change log | سجل التغيير | ما تغيّر، ولماذا، ومن قرر، والنتيجة قبل وبعد |
| Rollback | الرجوع | العودة إلى الحالة السابقة للتغيير |
| Incident | الحادثة | رد خاطئ وصل لعميل، أو تنفيذ بلا موافقة، أو تسرب، أو تكلفة لم تُفسَّر |
| Step cost | تكلفة في درجات | تكلفة لا تكبر مع كل مهمة، وإنما حين تمتلئ طاقة: مشغّلة ثانية مثلاً |

## الحوكمة والأمن

| English | العربية | المعنى في هذا المقرر |
|---|---|---|
| AI risk register | سجل مخاطر الذكاء الاصطناعي | مخاطر تخص المنتج، لكل منها مالك وضابط وحالة |
| Control | الضابط | ما يمنع الخطر أو يكشفه، وأين يُفرض |
| Likelihood and impact | الاحتمال والأثر | 1 إلى 3 لكل منهما، والدرجة حاصل ضربهما |
| Disclosure | الإفصاح | إعلام المستخدم بأنه يتعامل مع مساعد آلي |
| Audit log | سجل التدقيق | من طلب، وماذا نفّذ الوكيل، ومتى تدخّل إنسان |
| Service level | مستوى الخدمة | ما تلتزم به في عقد: زمن رد، توافر، وأحياناً دقة |
| Direct prompt injection | حقن التعليمات المباشر | ما يكتبه المستخدم ليتجاوز القواعد |
| Indirect prompt injection | حقن التعليمات غير المباشر | تعليمات مخفية في محتوى يقرؤه الوكيل |
| Tool misuse | إساءة استخدام الأدوات | استخدام أداة مشروعة استخداماً غير آمن |
| Excessive agency | الاستقلالية المفرطة | وظائف أو صلاحيات أو استقلالية أكثر مما تحتاجه المهمة |
| Least privilege | أقل صلاحية | أقل ما تحتاجه المهمة من وصول |
| Least agency | أقل استقلالية | لا قدرة للوكيل لا تحتاجها مهمته |
| Memory poisoning | تسميم الذاكرة | معلومة كاذبة تُخزَّن فتؤثر في قرارات لاحقة |
| Secrets management | إدارة الأسرار | حفظ المفاتيح خارج الشيفرة والتعليمات والسياق، وتدويرها |
| Kill switch | مفتاح الإيقاف | يعزل الوكيل فوراً ويحوّل العمل إلى إنسان |
| Red teaming | الاختبار العدائي | مهاجمة نظامك أنت في بيئة اختبار لتعرف أين ينكسر |
