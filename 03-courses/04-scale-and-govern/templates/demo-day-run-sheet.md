## 5. الأسئلة · Questions

| السؤال · Question | جوابك في سطرين · Your answer in two lines | الدليل في الملحق · Evidence in the appendix |
|---|---|---|
| ماذا يحدث لهامشكم إن تغيّرت أسعار النماذج؟ · What happens to your margin if model prices change? | | |
| ما الذي يمنع المزوّد أو منافساً من فعل الشيء نفسه؟ · What stops the provider or a competitor doing the same? | | |
| ماذا يحدث حين يخطئ الوكيل، ومن المسؤول؟ · What happens when the agent is wrong, and who is responsible? | | |
| أين تُعالَج بيانات العملاء؟ · Where is customer data processed? | | |
| كم يكلّف الحصول على عميل، وكم يبقى؟ · What does a customer cost to acquire and how long do they stay? | | |
| هل تعمل المنشأة إن غاب المؤسس شهراً؟ · Does the company run if the founder is away for a month? | | |

## 6. قبل الصعود · Before you go on

- [ ] كل رقم في الشرائح له مصدر · Every number on the slides has a source
- [ ] لا بيانات عملاء حقيقية على الشاشة · No real customer data on screen
- [ ] مفتاح الإيقاف والتسجيل الاحتياطي جُرّبا اليوم · Stop switch and backup recording tested today
- [ ] عرضتَ أمام شخصين بساعة توقيت · Rehearsed in front of two people with a timer
- [ ] «لا نعرف بعد» جاهزة لما لا تعرفه · "We do not know yet" is ready for what you do not know

**Rules.** A recording is announced as a recording. Nothing staged is presented as live. No reviewer is hidden behind the demo.
