## 2. بوابات التحقق · Validation gates

Checked before the pack is graded. Any "no" returns it.

| # | البوابة · Gate | نعم / لا · Yes / No | الدليل · Evidence |
|---|---|---|---|
| 1 | دليل التخرج حقيقي ويُتحقق منه، ومسمّى باسمه (خطاب النوايا ليس عميلاً) · Graduation evidence is real, checkable and named for what it is (an LOI is not a customer) | | |
| 2 | ورقة المؤشرات من سجل، أو مكتوب بوضوح أنها بيانات تجربة أو مصطنعة، ولم يُحذف منها أسبوع · The KPI sheet comes from a log, or is plainly labelled pilot or synthetic data, and no week was removed | | |
| 3 | لكل قرار مؤثر في المعمارية مالك مسمّى، ولا وكيل ينفّذ ما له أثر جوهري بلا موافقة بشرية · Every consequential decision has a named owner, and no agent acts with material effect without human approval | | |
| 4 | سجل المخاطر فيه ستة مخاطر على الأقل بكلمات المنتج، لكل منها مالك وضابط قائم أو خطة مؤرخة، ولا سطر منسوخ من القالب · At least six risks in the product's own words, each with an owner and a control that exists or a dated plan, and no row copied from the template | | |
| 5 | العرض يذكر نسبة النجاح بأعدادها وما لا يفعله الوكيل، ولا رقم فيه بلا مصدر، ولا شيء مرتَّب قُدِّم على أنه حي · The pitch states the success rate with its counts and what the agent does not do, has no unsourced number, and presents nothing staged as live | | |
