## 2. بوابات التحقق · Validation gates

Checked before the pack is graded. Any "no" returns it.

| # | البوابة · Gate | نعم / لا · Yes / No | الدليل · Evidence |
|---|---|---|---|
| 1 | المستخدم التجريبي من منشأة حقيقية، وليس المؤسس ولا أحد فريقه · The pilot user is from a real business and is not the founder or a team member | | |
| 2 | تكلفة المهمة المنجزة محسوبة من سجل، أو مكتوب بوضوح أنها تقدير ومن أين · Cost per resolved task comes from a log, or is plainly marked as an estimate with its basis | | |
| 3 | لا بيانات شخصية حقيقية عولجت قبل اتفاق مكتوب مع المنشأة · No real personal data was processed before a written agreement with the business | | |
| 4 | لا عميل أو مرجع أو نتيجة أو اعتماد مختلق أو غير مثبت · No invented or unproven customer, reference, result or accreditation | | |
| 5 | عروض التجربة أرسلها المتعلم نفسه إلى ثلاث منشآت حقيقية على الأقل، والردود كلها مسجّلة ومنها الرفض · Pilot offers were sent by the learner to at least three real businesses, and every reply is recorded, refusals included | | |
