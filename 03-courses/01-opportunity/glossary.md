# مسرد المقرر 1 · Course 1 glossary

<div dir="rtl">

المصطلح الإنجليزي يُذكر عند أول ورود في الدروس مع مقابله العربي. في الأطروحة الموجهة للمشتري لا تُستخدم مصطلحات تقنية.

## الوكلاء

| English | العربية | المعنى في هذا المقرر |
|---|---|---|
| Agent | الوكيل | نظام له هدف وأدوات وذاكرة وحلقة قرار |
| Chatbot | المحادث الآلي | يجيب ولا ينفّذ خارج المحادثة |
| Workflow automation | أتمتة سير العمل | خطوات ثابتة بلا قرار |
| Tool use | استخدام الأدوات | قدرة النظام على الفعل: قراءة نظام، إرسال رسالة |
| Memory / State | الذاكرة والحالة | ما يعرفه النظام عمّا أُنجز وعن العميل |
| Autonomy ladder | سلّم الاستقلالية | مستويات من الرد المكتوب إلى عدة وكلاء |
| Bounded autonomy | الاستقلالية المحدودة | نطاق وسقف وبوابات موافقة ومسار تصعيد، كلها مكتوبة |
| Approval gate | بوابة الموافقة | فعل لا يتم إلا بموافقة إنسان |
| Escalation path | مسار التصعيد | متى يتوقف الوكيل ولمن يسلّم |
| Human-in-the-loop | الإشراف البشري | إنسان يراجع أو يوافق أو يقرر؛ وبمعناه الضيق: يراجع الفعل قبل تنفيذه |
| Human-on-the-loop | المراقبة البشرية للتنفيذ | إنسان يراقب التشغيل ويتدخل عند الحاجة |
| Human-in-command | القيادة البشرية | إنسان يملك قرار استخدام النظام وحدوده وإيقافه |
| Verification tax | ضريبة التحقق | تكلفة التأكد من صحة ما أنتجه النظام |
| Multi-agent system | نظام متعدد الوكلاء | عدة وكلاء متخصصين؛ يُستخدم بعد إثبات الحاجة |

## العمليات

| English | العربية | المعنى |
|---|---|---|
| Task | مهمة | خطوة واحدة |
| Workflow | مسار عمل | خطوات متتابعة تنتج نتيجة واحدة |
| Business process | عملية | دورة كاملة من عدة مسارات |
| Workflow wedge | وتد سير العمل | مسار واحد مؤلم ومتكرر وغني بالقواعد وله مشترٍ |
| System of record | نظام السجل | الموضع الذي تُعتمد فيه الحقيقة |
| Trigger | المشغِّل | ما يبدأ المسار |
| Touch time | زمن العمل | دقائق العمل الفعلي على المعاملة |
| Waiting time | زمن الانتظار | الوقت الذي تبقى فيه المعاملة بلا عمل |
| First-pass yield | الإنجاز الصحيح من أول مرة | نسبة المعاملات التي تمر بلا رجوع |
| Exception rate | نسبة الاستثناءات | نسبة ما يخرج عن المسار المعتاد |
| Rework | إعادة العمل | تصحيح ما أُنجز خطأً |
| Handoff | التسليم | انتقال المعاملة من شخص إلى آخر |
| Integration surface | سطح التكامل | عدد الأنظمة التي يجب الاتصال بها وطريقة ذلك |
| Gemba | موقع العمل الفعلي | المكان الذي تُصنع فيه القيمة؛ تذهب إليه لتراقب |
| Work-as-done | العمل كما يُنجز | ما يحدث فعلاً، مقابل ما يُتخيَّل أو يُكتب أو يُحكى |
| Invisible work | العمل الخفي | عمل متكرر لا يظهر في إجراء ولا مؤشر، وأدواته غير الرسمية |
| Unwritten rule | قاعدة غير مكتوبة | قرار يعتمد على معرفة في رأس الموظف لا في النظام |
| Bottleneck | نقطة الاختناق | خطوة يتكدس عندها العمل |
| Failure point | نقطة الفشل | خطوة يكثر فيها الخطأ |
| Root cause | السبب الجذري | ما يمكن تغييره ليزول العَرَض |
| Waste | الهدر | خطوة لا تضيف قيمة ولا تفرضها ضرورة |
| Cycle time | زمن الدورة | من المشغِّل إلى اكتمال المعاملة، عملاً وانتظاراً |
| Process cycle efficiency | كفاءة دورة العملية | دقائق العمل المضيف للقيمة ÷ زمن الدورة |
| Rework rate | نسبة إعادة العمل | نسبة المعاملات التي أُعيدت معالجتها |
| Loaded cost | التكلفة المحمّلة | كل ما يكلفه الموظف المنشأة، لا راتبه الأساسي وحده |
| Cost of delay | تكلفة التأخير | ما تخسره المنشأة بسبب الانتظار |
| Observer effect | أثر المراقبة | تغيّر سلوك من يعلم أنه مراقَب |

## اكتشاف العملاء

| English | العربية | المعنى |
|---|---|---|

| Said versus did | قيل مقابل فُعل | الفرق بين الوصف والسلوك |
| Disconfirming evidence | الدليل الناقض | ما يخالف فرضيتك |
| Confirmation bias | الانحياز التأكيدي | سماع ما يوافقك فقط |
| Saturation | التشبّع | مقابلتان متتاليتان بلا نمط جديد |
| Willingness to pay | الاستعداد للدفع | يُستدل عليه بإنفاق قائم أو التزام |
