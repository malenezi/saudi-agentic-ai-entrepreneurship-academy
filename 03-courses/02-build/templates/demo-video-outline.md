# مخطط العرض المصوّر · Demo video outline

Used in [Module 2.8](../lessons/2-8-failure-analysis-and-iteration.md). Three minutes, in Arabic. Record the screen with the agent running; slides are optional. Use test or anonymised data and never show an access key.

<div dir="rtl">

| الزمن | المقطع | ما يُعرض | نصك |
|---|---|---|---|
| 0:00 إلى 0:25 | المشكلة والعميل | من العميل، وما العمل المتكرر المكلف | |
| 0:25 إلى 0:55 | التصميم والحدود | ورقة التصميم: الهدف، الأدوات، ما لا يفعله | |
| 0:55 إلى 1:50 | الوكيل يعمل | حالة عادية باللهجة من أولها إلى آخرها، ثم حالة استثنائية يتوقف فيها أو يحيل | |
| 1:50 إلى 2:25 | نتائج التقييم | الجدول: خط الأساس وبعد الدورتين، واللهجة وحدها، وما بقي | |
| 2:25 إلى 2:50 | الضوابط | بوابة موافقة وهي توقف إجراءً، ومحاولة حقن وهي تفشل | |
| 2:50 إلى 3:00 | الدرس الأهم | جملة واحدة | |

## قبل التسجيل

- [ ] كل ما على الشاشة بيانات تجريبية أو منزوعة الهوية.
- [ ] لا مفاتيح وصول ولا عناوين أنظمة داخلية ظاهرة.
- [ ] في العرض حالة توقف أو فشل واحدة على الأقل.
- [ ] الأرقام المعروضة هي أرقام سجل التشغيل، لا أرقام تقريبية.
- [ ] شاهده شخص لم يشارك في البناء وفهم ما يفعله الوكيل وما لا يفعله.
