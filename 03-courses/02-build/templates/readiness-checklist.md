# قائمة التحقق قبل الاعتماد · Readiness checklist

Used at the end of [Module 2.8](../lessons/2-8-failure-analysis-and-iteration.md), before submitting the Course 2 deliverable. A tick means there is evidence you can show, not an intention. The four gates at the end are the [validation gates](../rubrics.md#2-validation-gates): any "no" returns the project.

<div dir="rtl">

## التصميم

- [ ] الهدف نتيجة يمكن التحقق منها، والنطاق وما هو خارجه مكتوبان.
- [ ] سبب استخدام وكيل (لا أتمتة عادية) مكتوب، أو القرار أن الأتمتة تكفي.
- [ ] المدخلات والمخرجات والأدوات معروفة.
- [ ] مستوى الاستقلالية محدد على سلّم المقرر 1.
- [ ] معيار قبول العميل مكتوب.

## السياق والعربية

- [ ] التعليمات بأقسامها التسعة، ولا تعارض بينها.
- [ ] مصادر المعرفة معروفة، ولكل وثيقة تاريخ اعتماد.
- [ ] اختُبرت الفصحى واللهجة السعودية والكتابة المختلطة.
- [ ] اختُبرت التواريخ والأرقام والمبالغ والأسماء.
- [ ] المخرجات المنظمة تُفحص قبل أن تصل إلى أي نظام.
- [ ] راجع النبرة شخص سعودي.

## الأدوات

- [ ] لكل أداة عقد مكتوب وصلاحية محدودة.
- [ ] الوكيل يعمل بحساب خدمة، لا بحساب شخصي.
- [ ] لكل خطأ متوقع تصرف محدد، وإعادة المحاولة محدودة.
- [ ] لا مفاتيح وصول في التعليمات ولا في السجلات.
- [ ] عمليات الكتابة يُتحقق منها بعد التنفيذ، ولا تتكرر عند إعادة المحاولة.

## التقييم

- [ ] 30 حالة على الأقل، منها 10 على الأقل باللهجة السعودية، وفئة أمان وصلاحيات.
- [ ] نصف الحالات على الأقل من مواقف حقيقية، وكل البيانات الشخصية مستبدلة.
- [ ] معايير النجاح وقاعدة الإطلاق كُتبت قبل التشغيل.
- [ ] كل حالة شُغّلت ثلاث مرات، والمتذبذبة مسجّلة.
- [ ] نسبة النجاح مقاسة للمجموعة ولكل فئة، ومعها التكلفة والزمن.
- [ ] المجموعة كلها أُعيدت بعد كل تغيير.

## الضوابط والحوكمة

- [ ] مصفوفة الإشراف فيها صف لكل فعل تتيحه الأدوات.
- [ ] حاولنا تنفيذ كل إجراء من المستوى D وفشلت المحاولة.
- [ ] كل إجراء من المستوى C توقف فعلاً بانتظار الموافقة.
- [ ] اختُبر حقن التعليمات المباشر وغير المباشر.
- [ ] حدود الخطوات والإنفاق ومفتاح الإيقاف محددة.
- [ ] السجلات منقّحة، ومدة الاحتفاظ بها ومن يطّلع عليها محددان.

## التحسين

- [ ] الإخفاقات مصنّفة بالفئات الأربع، ولكل نمط سبب.
- [ ] دورتان منفّذتان، في كل منهما تغيير واحد موثق.
- [ ] النتائج قبل وبعد مقارنة: الجودة، التكلفة، الزمن، المخاطر.
- [ ] ما لم يُعالَج مكتوب.
- [ ] العرض المصوّر يُظهر القدرات والحدود، وفيه حالة توقف أو فشل.

## بوابات التحقق

- [ ] لا إجراء حساس يُنفَّذ دون موافقة.
- [ ] لا كشف لبيانات غير مصرّح بها.
- [ ] يوجد اختبار يمكن لغيرك أن يعيد تشغيله ويتحقق من نتيجته.
- [ ] لا إخفاق جوهري مخفي.
