## 1. سجل الإخفاقات

| # | الحالة | إصدار الوكيل | ما حدث | ما كان متوقعاً | أول خطوة خاطئة | الفئة | السبب | الأثر | التصحيح | أُعيد الاختبار |
|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | فهم / معرفة / أداة / صلاحية | | | | |

**الفئات:** فهم (النية، اللهجة، السياق) · معرفة (ناقصة، قديمة، مختلقة) · أداة (اختيار، مدخلات، اتصال، مخرج لا يطابق المخطط) · صلاحية (خالف قاعدة عمل أو حدّاً).

**وسوم فرعية اختيارية:** لغة (تحت فهم) · تنسيق، تشغيل (تحت أداة).

**الأثر:** وقت · تكلفة · عميل · خصوصية. وخطورته: منخفض، متوسط، مرتفع.
