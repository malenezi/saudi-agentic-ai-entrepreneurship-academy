# مسرد المقرر 2 · Course 2 glossary

<div dir="rtl">

المصطلح الإنجليزي يُذكر عند أول ورود في الدروس مع مقابله العربي. ما ورد في [مسرد المقرر 1](../01-opportunity/glossary.md) (الوكيل، المحادث الآلي، سلّم الاستقلالية، بوابة الموافقة، مسار التصعيد، نسبة النجاح، تكلفة المهمة المنجزة) لا يتكرر هنا. لتوحيد مصطلحات مشروعك أنت استخدم [تمرين B6](../../05-agentic-ai-lab/exercises/b6-terminology.md).

## التصميم والسياق

| English | العربية | المعنى في هذا المقرر |
|---|---|---|
| Agent design sheet | ورقة تصميم الوكيل | الهدف والتعليمات والمعرفة والأدوات والذاكرة والحدود، قبل البناء |
| Instructions / System prompt | التعليمات (تعليمات النظام) | الدور والأولويات والقيود التي يقرؤها النموذج في كل تشغيل |
| Context engineering | هندسة السياق | تصميم ما يراه النموذج وقت التنفيذ |
| Context window | نافذة السياق | أقصى ما يتسع له النموذج من رموز في تشغيل واحد |
| Token | الرمز | وحدة النص التي يعدّها النموذج ويحاسب عليها المزوّد |
| Retrieval-augmented generation (RAG) | التوليد المعزز بالاسترجاع | استرجاع مقاطع من مصدر معرفة وإضافتها للسياق. لا يضمن صحة الإجابة وحده |
| Source of truth | مصدر الحقيقة | النظام أو الوثيقة المرجع عند الخلاف |
| Structured output | المخرجات المنظمة | استجابة ببنية وحقول محددة يفحصها برنامج |
| Schema | المخطط | تعريف الحقول وأنواعها والقيم المسموح بها |
| Hallucination | الاختلاق | معلومة تبدو معقولة ولا يسندها مصدر |
| Code-switching | الكتابة المختلطة | عربية وإنجليزية في رسالة واحدة |
| ReAct | نمط الاستدلال والفعل | تناوب بين استدلال وفعل وقراءة نتيجة |

## الأدوات والنماذج

| English | العربية | المعنى |
|---|---|---|
| Tool calling | استدعاء الأدوات | النموذج يطلب تنفيذ وظيفة محددة، والتطبيق ينفّذ |
| Tool contract | عقد الأداة | الاسم والغرض والمدخلات والمخرجات والصلاحية والأخطاء وشروط الاستدعاء والتوقف |
| Least privilege | أقل الصلاحيات | لا صلاحية أوسع مما تحتاجه المهمة |
| Excessive agency | الاستقلالية المفرطة | وظائف أو صلاحيات أو استقلالية أكثر من الحاجة |
| Service account | حساب الخدمة | حساب خاص بالوكيل محدود الصلاحيات |
| Model Context Protocol (MCP) | بروتوكول سياق النموذج | معيار مفتوح لإتاحة الأدوات والموارد لتطبيقات الذكاء الاصطناعي |
| Idempotency key | مفتاح منع التكرار | يضمن ألا يُنفَّذ الطلب المعاد مرتين |
| Hosted model | نموذج مستضاف | يعمل عند المزوّد ويُستدعى عبر واجهة برمجية |
| Open-weight model | نموذج مفتوح الأوزان | أوزانه متاحة وفق ترخيص؛ لا يعني بيانات مفتوحة ولا استخداماً بلا قيود |
| Latency | زمن الاستجابة | الوقت حتى تظهر النتيجة |
| Cost per successful task | التكلفة لكل مهمة ناجحة | تكلفة التشغيل مقسومة على المهام التي اجتازت المعيار |

## التقييم

| English | العربية | المعنى |
|---|---|---|
| Evaluation set | مجموعة التقييم | حالات تمثّل العمل الفعلي، لكل منها معيار نجاح |
| Pass criterion | معيار النجاح | شرط يُجاب عنه بنعم أو لا، يُكتب قبل التشغيل |
| Baseline | خط الأساس | أول قياس كامل، تُقارن به كل دورة |
| Release rule | قاعدة الإطلاق | النسبة المطلوبة والحالات التي يجب ألا تفشل، تُكتب قبل التشغيل |
| Abstention | الامتناع | أن يتوقف الوكيل أو يطلب أو يحيل؛ نجاح إن كان هو المطلوب |
| Held-back set | المجموعة المحجوزة | حالات لا تُستخدم في التطوير، تُشغَّل قبل القرار |
| Flaky case | حالة متذبذبة | تنجح مرة وتفشل مرة في التشغيل المكرر |
| LLM-as-a-judge | النموذج الحَكَم | نموذج يقيّم مخرجات نموذج وفق سلّم؛ مساعد لا حكم وحيد |
| Regression testing | الاختبار الرجعي | إعادة المجموعة كلها بعد أي تغيير |

## الضوابط والتحسين

| English | العربية | المعنى |
|---|---|---|
| Guardrails | ضوابط الحماية | قيود تُفرض في التطبيق، لا في التعليمات |
| Allow-list | قائمة السماح | ما يُسمح به صراحة؛ ما عداه ممنوع |
| Human oversight matrix | مصفوفة الإشراف البشري | مستوى إشراف لكل فعل: مستقل، إشعار، موافقة، محظور |
| Prompt injection | حقن التعليمات | تعليمات مدسوسة في رسالة أو محتوى تحاول تغيير سلوك النموذج |
| Indirect injection | الحقن غير المباشر | النص المدسوس في محتوى يقرؤه الوكيل، لا في رسالة المستخدم |
| Untrusted content | محتوى غير موثوق | كل ما يأتي من خارج تعليماتك: رسائل، ملفات، نتائج أدوات |
| Kill switch | مفتاح الإيقاف | وسيلة يملكها إنسان محدد لإيقاف الوكيل فوراً |
| Observability / Logging | قابلية الرصد والتسجيل | معرفة ما حدث من السجلات والقياسات |
| Trace | مسار التنفيذ | خطوات الوكيل في مهمة واحدة بترتيبها |
| Coordinator | المنسّق | وكيل يوزع العمل على وكلاء متخصصين |
| Sequential pipeline | الخط المتتابع | مراحل بترتيب ثابت، مخرج كل منها مدخل التالية |
| Reviewer pattern | نمط المراجِع | وكيل ينتج وآخر يراجع وفق معايير |
| Handoff | التسليم | انتقال المهمة وسياقها من وكيل إلى آخر أو إلى إنسان |
| Failure analysis | تحليل الإخفاق | تصنيف الأخطاء ومعالجة أسبابها |
| Error class | فئة الخطأ | فهم، معرفة، أداة، صلاحية |
| Improvement cycle | دورة التحسين | قياس، تصنيف، تغيير واحد، إعادة المجموعة كلها، مقارنة |
