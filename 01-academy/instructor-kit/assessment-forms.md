## 1. تقييم الأقران

يملؤه كل عضو عن كل زميل في فريقه، منفرداً، بعد البوابتين 2 و4. لا يراه الزملاء.

|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

- **المشاركة:** حضر، وناقش، وأجرى مقابلات أو اختبارات بنفسه.
- **الالتزام:** سلّم ما وعد به في وقته، وأبلغ مبكراً حين تأخر.
- **الجودة:** ما سلّمه استُخدم كما هو أو بتعديل يسير.

**قاعدة:** درجة بلا مثال لا تُحتسب. ولا يُقيَّم الزميل على ما كتبه مساعده الذكي، وإنما على ما راجعه وقرّره.

سؤالان مفتوحان: ما الذي فعله الفريق جيداً ويجب أن يكرره؟ ما الذي ستغيّره لو بدأتم من جديد؟

## 2. ورقة لجنة التحكيم

عرض عشر دقائق، ثم خمس للأسئلة. يملؤها كل محكّم منفرداً، ثم تُجمع.

**الفريق:** ____ · **المشروع:** ____ · **المحكّم:** ____

| المعيار | الوزن | ما يبحث عنه المحكّم | الدرجة من 5 |
|---|---|---|---|
| **الدليل** | 30% | مقابلات حقيقية، مجموعة اختبار من حالات واقعية، أرقام من سجل، لا من تقدير | |
| **المحتوى** | 25% | المشكلة واضحة، الوكيل يؤدي مهمة واحدة محددة، الحدود والموافقات مذكورة | |
| **الصدق في الحدود** | 15% | ما لم ينجح معروض، وما لم يُصلح مذكور، ولا رقم بلا مصدر | |
| **الأسئلة والأجوبة** | 15% | إجابات مباشرة؛ «لا نعرف بعد» إجابة مقبولة حين تكون صحيحة | |
| **الإلقاء وإدارة الوقت** | 10% | وضوح، وتوزيع أدوار، والتزام بالدقائق العشر | |
| **تصميم العرض** | 5% | مقروء بالعربية، واتجاه سليم، وشريحة لكل فكرة | |

**المجموع من 5** = مجموع (الدرجة × الوزن). مثال: 4، 4، 3، 3، 5، 4 تعطي 1.2 + 1.0 + 0.45 + 0.45 + 0.5 + 0.2 = **3.8**.

**سؤال واحد على كل محكّم أن يطرحه:** ما الذي كان سيجعلكم تتوقفون عن هذا المشروع، وهل حدث؟

ملاحظتان للفريق، مكتوبتان: أقوى دليل رأيته، وأول ما كنت سأتحقق منه لو كنت مستثمراً.

## 3. ورقة تحكيم تمرين البناء

لتمرين الثماني والأربعين ساعة. المشكلة من منشأة حقيقية، وصاحبها أو من يمثله في اللجنة إن أمكن.

**الفريق:** ____ · **المشكلة:** ____ · **صاحب المشكلة:** ____

| المعيار | الوزن | ما يبحث عنه المحكّم | الدرجة من 5 |
|---|---|---|---|
| **فهم المشكلة من صاحبها** | 25% | تحدثوا إليه، ووصفوا سير العمل بكلماته، وحددوا مهمة واحدة | |
| **وكيل يعمل** | 25% | عرض حي على حالات لم يحضّرها الفريق، منها حالة يقترحها صاحب المشكلة | |
| **مجموعة اختبار** | 20% | عشرون حالة على الأقل، ونسبة نجاح مقيسة، وحالات فاشلة معروضة | |
| **الحدود والأمان** | 15% | ما لا يفعله الوكيل، وما يحتاج موافقة، وحالة رفض أو تصعيد في العرض | |
| **الطريق إلى الاستخدام** | 15% | ماذا ينقص ليُجرَّب في المنشأة الأسبوع القادم، وكم يكلّف تشغيله | |

**قواعد التمرين:** بيانات مصطنعة أو مجهّلة فقط. لا وصول إلى أنظمة المنشأة الحية. ما يُبنى يبقى ملكاً لأصحابه بحسب ما اتُّفق عليه كتابةً قبل البدء. والفريق الذي يعرض إخفاقاته لا يُخصم منه: يُخصم ممن أخفاها.

**English.** Three printable forms with suggested weights. (1) Peer evaluation: participation, commitment and quality, each 1 to 5, with a specific example required for every score. (2) Panel sheet for a ten-minute presentation with five minutes of questions: evidence 30%, content 25%, honesty about limits 15%, questions and answers 15%, delivery and time 10%, slide design 5%. (3) Buildathon judging sheet for a 48-hour sprint on a real problem from a small business: understanding the problem from its owner 25%, a working agent on unprepared cases 25%, a test set 20%, limits and safety 15%, path to use 15%. The peer and panel forms adapt those of the author's earlier university course, with evidence moved to first place.
