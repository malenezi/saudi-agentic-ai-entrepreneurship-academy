## 1. الأسئلة السبعة · The seven questions

| # | السؤال | Question | نعم / لا | الدليل الذي رأيته |
|---|---|---|---|---|
| 1 | **العمل معروف.** هل للمهمة خطوات يمكن وصفها، وهل رُوقبت وهي تُؤدّى؟ | <bdi dir="ltr" lang="en">Is the task describable, and has it been observed?</bdi> | | |
| 2 | **البيانات متاحة.** هل ما يحتاج إليه الوكيل موجود في نظام يمكن الوصول إليه، لا في رؤوس الموظفين ورسائلهم؟ | <bdi dir="ltr" lang="en">Is what the agent needs in a system that can be reached?</bdi> | | |
| 3 | **للقرار صاحب.** هل يوجد شخص مسمّى يملك قرار التجربة وحدود الوكيل وإيقافه؟ | <bdi dir="ltr" lang="en">Is there a named person who owns the pilot, the limits and the stop?</bdi> | | |
| 4 | **للمراجعة وقت.** هل يوجد موظف يعرف العمل وله وقت لمراجعة مخرجات الوكيل في أسابيعه الأولى؟ | <bdi dir="ltr" lang="en">Is there staff time to review the agent's output at first?</bdi> | | |
| 5 | **الخطأ محتمل.** هل للخطأ في هذه المهمة رجعة، وتكلفته محتملة؟ | <bdi dir="ltr" lang="en">Is an error in this task recoverable and affordable?</bdi> | | |
| 6 | **البيانات مأذونة.** هل يجوز نظاماً معالجة هذه البيانات بهذه الطريقة، وهل اتُّفق على ذلك كتابةً؟ | <bdi dir="ltr" lang="en">May this data lawfully be processed this way, and is that agreed in writing?</bdi> | | |
| 7 | **للقياس أساس.** هل يُعرف اليوم كم مهمة تُنجز، وكم تأخذ، وكم يُخطأ فيها؟ | <bdi dir="ltr" lang="en">Is today's volume, time and error rate known?</bdi> | | |

## 2. القرار · Decision

| الحال | من أين تبدأ | In English |
|---|---|---|
| سبع إجابات «نعم» | تجربة تبدأ بوضع الظل، ثم تشغيل بموافقة على كل فعل | <bdi dir="ltr" lang="en">Seven yes: a pilot that opens in shadow mode, then approval on every action</bdi> |
| «لا» في 1 أو 7 | مراقبة سير العمل وقياسه أولاً؛ لا تجربة بعد | <bdi dir="ltr" lang="en">No on 1 or 7: observe and measure the work first; no pilot yet</bdi> |
| «لا» في 2 | وكيل يقرأ فقط مما هو متاح، أو تأجيل حتى تُنظَّم البيانات | <bdi dir="ltr" lang="en">No on 2: a read-only agent on what is reachable, or wait</bdi> |
| «لا» في 3 أو 4 | لا تجربة حتى يُسمّى الشخص ويُخصَّص الوقت | <bdi dir="ltr" lang="en">No on 3 or 4: no pilot until the person is named and the time set aside</bdi> |
| «لا» في 5 أو 6 | مهمة أخرى، أو إعادة تصميم تُبقي الفعل الخطر عند إنسان | <bdi dir="ltr" lang="en">No on 5 or 6: another task, or a redesign that keeps the risky act with a person</bdi> |
