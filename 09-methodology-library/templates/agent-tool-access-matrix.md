*Oversight level* uses the letters of the human oversight matrix: A autonomous, B notify, C approve, D forbidden. *Account used:* a service account of the agent's own with limited permissions, never a person's account.

المنع يكون خارج النموذج: صلاحية لم تُمنح، أو مفتاح غير متاح للوكيل. جملة في التعليمات ليست منعاً.

Prevention sits outside the model: a permission not granted, or a key the agent does not hold. A sentence in the instructions is not prevention.

## 3. المراجعة · Review

- [ ] كل أداة كتابة لها مستوى B أو C، أو سبب مكتوب لكونها A · <bdi dir="ltr" lang="en">Every write tool is at level B or C, or has a written reason for A</bdi>
- [ ] لا فعل بلا رجعة عند المستوى A · <bdi dir="ltr" lang="en">No irreversible action at level A</bdi>
- [ ] لا أداة لم تُستخدم منذ المراجعة السابقة؛ ما لم يُستخدم يُسحب · <bdi dir="ltr" lang="en">No tool unused since the last review; what was not used is withdrawn</bdi>
- [ ] الحسابات كلها حسابات خدمة · <bdi dir="ltr" lang="en">All accounts are service accounts</bdi>
- [ ] لكل أداة عقد مكتوب · <bdi dir="ltr" lang="en">Every tool has a written contract</bdi>
