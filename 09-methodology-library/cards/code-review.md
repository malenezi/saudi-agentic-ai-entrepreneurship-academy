# مراجعة الشيفرة · Code Review

<div dir="rtl">

**النوع:** منهجية · **المستوى:** تطبيقي · **المجال:** تطوير البرمجيات والتشغيل · **المنشأ:** معروف عالمياً · **المرحلة:** بناء الوكيل، التوسع والحوكمة

## الغرض

ألّا يدخل الشيفرة ما لم يقرأه أحد. دليل Google المنشور يجعل المعيار هكذا: يوافق المراجع على التغيير متى صار يحسّن صحة الشيفرة إجمالاً تحسيناً واضحاً، وإن لم يبلغ الكمال. ومن مبادئه: الوقائع والبيانات تتقدم على الآراء والتفضيلات، ودليل الأسلوب هو المرجع في الأسلوب، وقرارات التصميم تُوزن بمبادئ الهندسة لا بالذوق ([A248](../../SOURCES.md)). وحين يكتب وكيل البرمجة أكثر الشيفرة تصير المراجعة هي عمل الإنسان الأول.

## متى يُستخدم

- لكل تغيير يدخل الفرع الرئيسي، كتبه إنسان أو وكيل.
- لتغيير في التعليمات أو في مصفوفة الإشراف كما في الشيفرة.
- عند انضمام مطوّر جديد؛ بها يتعلم المشروع.

## متى لا يُستخدم

- بتغييرات من ألف سطر؛ قسّمها.
- جدالاً في الذوق.
- ختماً شكلياً يُمنح دون قراءة.

## المدخلات

- تغيير صغير له وصف: ماذا ولماذا.
- اختبارات ناجحة.
- دليل أسلوب، ولو صفحة.

## الخطوات

1. اقرأ الوصف: ما المشكلة، وهل يحلها التغيير؟
2. اقرأ الاختبارات قبل الشيفرة: هل تفحص ما يُدّعى؟
3. اقرأ الشيفرة: الصحة، ثم الوضوح، ثم ما يمس البيانات والصلاحيات.
4. علّق بالوقائع، وميّز اللازم من المقترح.
5. وافق متى صار التغيير تحسيناً؛ الباقي لتغيير تالٍ.

## القالب

| البند | نعم/لا | ملاحظة |
|---|---|---|
| الوصف يقول ماذا ولماذا | | |
| الاختبارات تفحص السلوك المدّعى | | |
| لا مفاتيح ولا بيانات عملاء في التغيير | | |
| ما يمس صلاحيات الوكيل أو حدوده راجعه مالكه | | |
| التغيير يحسّن الشيفرة إجمالاً | | |

## مثال توضيحي

**سيناريو توضيحي.** وكيل برمجة قدّم تغييراً يضيف أداة «إلغاء الطلب»، واختباراته خضراء. المراجِعة قرأت الاختبارات أولاً فوجدتها تفحص أن الإلغاء يقع، ولا تفحص أن الوكيل يستأذن قبله. الأداة كانت ستعمل بلا موافقة. أُعيد التغيير باختبار جديد يرسب إن نُفّذ الإلغاء دون موافقة مسجّلة.

## كيف يعين الوكيل الذكي

- يراجع أولاً: يلخّص التغيير ويشير إلى ما لا تغطيه الاختبارات.
- يتحقق من الأسلوب آلياً ليتفرغ الإنسان للمعنى.
- يكتب وصف التغيير من الفرق.
- **حدّه:** لا يوافق على تغيير كتبه هو، ولا يحلّ محل المراجع البشري في ما يمس الصلاحيات.

## المخرج

تغيير مدموج قرأه إنسان غير كاتبه، ومعه سجل الملاحظات.

## معايير الجودة

- التغييرات صغيرة.
- الاختبارات قُرئت.
- الملاحظات وقائع لا أذواق.
- ما يمس الحدود راجعه مالكه.
