These are **hypotheses to test**, not validated opportunities. No market sizes are given, by design. Your job is to check a hypothesis against real businesses.

## How each brief is structured

Every opportunity in this repository is published in the same eight-part format. Contributors must use it.

1. Market problem
2. Potential customers
3. Existing alternatives (including "a person with a spreadsheet")
4. Evidence and source (interviews, official data; with dates)
5. Agent opportunity
6. Build complexity (low, medium, high) and why
7. Monetisation options
8. Regulatory and data considerations

Briefs below are at **seed level**: parts 1, 2, 5, 6, 7 and 8 are drafted; parts 3 and 4 are for learners and contributors to fill with evidence.

## 1. Accounting, tax and compliance for SMEs · المحاسبة والامتثال

| | |
|---|---|
| Problem | Small businesses spend hours matching invoices, bank lines and purchase records, and preparing VAT filings |
| Customers | Accounting offices, bookkeepers, SMEs without a finance team |
| Agent opportunity | Invoice intake and matching, exception flagging, draft VAT summaries, document chasing over WhatsApp |
| Complexity | Medium. Arabic documents, varied formats, integration with accounting software |
| Monetisation | Per document processed; per client per month for accounting offices |
| Considerations | Financial records and some personal data. A qualified person must approve filings. E-invoicing rules are set by ZATCA |

## 2. Healthcare administration · الإدارة الصحية

| | |
|---|---|
| Problem | Clinics lose revenue to missed appointments and staff time to booking, reminders and insurance paperwork |
| Customers | Private clinics, dental and specialist centres, medical complexes |
| Agent opportunity | Appointment booking and reminders on WhatsApp, pre-visit information collection, insurance-approval follow-up |
| Complexity | Medium to high. Integration with clinic systems; sensitive data |
| Monetisation | Per booked appointment; monthly subscription per clinic |
| Considerations | Health data is sensitive personal data under PDPL and the health sector has its own rules. **Administrative tasks only: no diagnosis or medical advice.** Take legal advice before handling patient data |

## 3. Tourism, Hajj and Umrah services · السياحة وخدمات الحج والعمرة

| | |
|---|---|
| Problem | Operators handle large volumes of multilingual enquiries, itinerary changes and coordination between providers |
| Customers | Tour operators, Umrah service companies, hotels, experience providers |
| Agent opportunity | Multilingual enquiry handling, itinerary building, booking changes, supplier coordination, post-trip follow-up |
| Complexity | Medium. Many languages and peak-season load |
| Monetisation | Per booking; per resolved enquiry; seasonal subscription |
| Considerations | Passport and travel data; licensing of the underlying service; accuracy of religious and official guidance must come from authorised sources, not from the model |

## 4. Retail and e-commerce · التجزئة والتجارة الإلكترونية

| | |
|---|---|
| Problem | Small online stores cannot answer every customer message, and lose sales after hours |
| Customers | Stores on local e-commerce platforms, social sellers, small chains |
| Agent opportunity | Sales and support on WhatsApp and social channels, order status, returns handling, product description writing in Arabic, restocking alerts |
| Complexity | Low to medium. Platforms and payment providers offer APIs |
| Monetisation | Per resolved conversation; percentage of recovered sales; subscription |
| Considerations | E-commerce and consumer-protection rules; customer contact data; clear handover to a person |

## 5. Logistics and last mile · الخدمات اللوجستية

| | |
|---|---|
| Problem | Dispatchers spend their day on address clarification, delivery exceptions and status calls |
| Customers | Last-mile carriers, fleet operators, merchants with their own delivery |
| Agent opportunity | Address confirmation with recipients, exception handling, rescheduling, proactive status updates, customs document preparation |
| Complexity | Medium. Real-time data and several parties |
| Monetisation | Per shipment handled; per exception resolved |
| Considerations | Location and contact data; integration with carrier systems; national address format |

## 6. Real estate · العقار

| | |
|---|---|
| Problem | Agents and brokers answer the same questions repeatedly and qualify many leads who never transact |
| Customers | Brokerages, developers' sales teams, property managers |
| Agent opportunity | Lead qualification, property matching, viewing scheduling, tenant requests and maintenance triage for property managers |
| Complexity | Low to medium |
| Monetisation | Per qualified lead; per unit managed per month |
| Considerations | Brokerage and advertising are regulated activities with licensing requirements; identity and financial data in rental processes |

## 7. Professional services · الخدمات المهنية

| | |
|---|---|
| Problem | Consulting, legal and recruitment firms spend senior time on research, first drafts and screening |
| Customers | Small consultancies, law offices, recruitment agencies, training providers |
| Agent opportunity | Tender and RFP monitoring and summarising, proposal first drafts, document review support, candidate screening and scheduling |
| Complexity | Low to medium for drafting; higher where judgement is regulated |
| Monetisation | Per document; per tender tracked; subscription |
| Considerations | Client confidentiality; professional responsibility stays with the licensed professional; fairness in candidate screening |

## 8. Education and training · التعليم والتدريب

| | |
|---|---|
| Problem | Training providers and schools handle heavy administrative load: enquiries, enrolment, scheduling, follow-up |
| Customers | Training institutes, private schools, tutoring centres, corporate academies |
| Agent opportunity | Enrolment and enquiry handling, learner follow-up, Arabic practice and tutoring assistants, content adaptation |
| Complexity | Low to medium |
| Monetisation | Per enrolled learner; subscription per institution |
| Considerations | Data about minors needs particular care and guardian involvement; educational accuracy |

## From brief to opportunity

1. Pick one brief.
2. Find three businesses in that sector and ask to observe the workflow.
3. Fill parts 3 and 4 with what you saw and heard.
4. Score it with the [AI Opportunity Assessment](../../04-entrepreneur-toolkit/02-ai-opportunity-assessment.md).
5. Contribute your evidence back (anonymised) by pull request so the next founder starts further ahead.
