# القطاعات والفرص

النسخة الإنجليزية: [Sectors and opportunities](sectors-and-opportunities.md) · آخر مراجعة: 16 نوفمبر 2026

**تنبيه مهم:** ما يلي **فرضيات** لنقطة البداية، وليست فرصاً مُثبتة. لا توجد هنا أحجام أسواق لأننا لا ننشر رقماً بلا مصدر ومنهجية. مهمتك أن تتحقق من الفرضية مع منشآت حقيقية.

## كيف يُبنى كل ملخص

تُنشر كل فرصة في هذا المستودع بالصيغة نفسها المكوّنة من ثمانية أجزاء. وعلى المساهمين الالتزام بها.

1. مشكلة السوق
2. العملاء المحتملون
3. البدائل القائمة (ومنها «شخص بجدول بيانات»)
4. الدليل والمصدر (مقابلات، وبيانات رسمية؛ مع التواريخ)
5. فرصة الوكيل الذكي
6. تعقيد البناء (منخفض، متوسط، مرتفع) وسببه
7. خيارات تحقيق الدخل
8. الاعتبارات التنظيمية واعتبارات البيانات

الملخصات أدناه في **مستوى البذرة**: الأجزاء 1 و2 و5 و6 و7 و8 مكتوبة، أما الجزآن 3 و4 فيملؤهما المتعلمون والمساهمون بالأدلة.

## 1. المحاسبة والضريبة والامتثال للمنشآت الصغيرة والمتوسطة

| | |
|---|---|
| المشكلة | تقضي المنشآت الصغيرة ساعات في مطابقة الفواتير وكشوف البنوك وسجلات المشتريات وإعداد إقرارات ضريبة القيمة المضافة |
| العملاء | مكاتب المحاسبة، ومسكو الدفاتر، والمنشآت الصغيرة والمتوسطة التي لا فريق مالياً لديها |
| فرصة الوكيل | استلام الفواتير ومطابقتها، وتنبيه الاستثناءات، ومسودات ملخصات ضريبة القيمة المضافة، ومتابعة المستندات عبر واتساب |
| التعقيد | متوسط. مستندات عربية، وصيغ متنوعة، وتكامل مع برامج المحاسبة |
| تحقيق الدخل | لكل مستند يُعالَج؛ ولكل عميل شهرياً لمكاتب المحاسبة |
| الاعتبارات | سجلات مالية وبعض البيانات الشخصية. يجب أن يعتمد شخص مؤهل الإقرارات. وقواعد الفوترة الإلكترونية تضعها هيئة الزكاة والضريبة والجمارك |

## 2. الإدارة الصحية

| | |
|---|---|
| المشكلة | تخسر العيادات إيراداتها بسبب المواعيد الفائتة، ووقت الموظفين بسبب الحجز والتذكير وأوراق التأمين |
| العملاء | العيادات الخاصة، ومراكز الأسنان والتخصصات، والمجمعات الطبية |
| فرصة الوكيل | حجز المواعيد والتذكير عبر واتساب، وجمع المعلومات قبل الزيارة، ومتابعة موافقات التأمين |
| التعقيد | متوسط إلى مرتفع. تكامل مع أنظمة العيادات؛ وبيانات حساسة |
| تحقيق الدخل | لكل موعد محجوز؛ واشتراك شهري لكل عيادة |
| الاعتبارات | البيانات الصحية بيانات شخصية حساسة بموجب نظام حماية البيانات الشخصية، وللقطاع الصحي قواعده الخاصة. **المهام الإدارية فقط: لا تشخيص ولا نصيحة طبية.** اطلب استشارة قانونية قبل التعامل مع بيانات المرضى |

## 3. السياحة وخدمات الحج والعمرة

| | |
|---|---|
| المشكلة | يتعامل المشغّلون مع أحجام كبيرة من الاستفسارات متعددة اللغات، وتغييرات برامج الرحلات، والتنسيق بين المزودين |
| العملاء | مشغلو الرحلات، وشركات خدمات العمرة، والفنادق، ومزودو التجارب |
| فرصة الوكيل | معالجة الاستفسارات بلغات متعددة، وبناء برامج الرحلات، وتعديل الحجوزات، والتنسيق مع الموردين، والمتابعة بعد الرحلة |
| التعقيد | متوسط. لغات كثيرة وضغط موسمي |
| تحقيق الدخل | لكل حجز؛ ولكل استفسار يُحَل؛ واشتراك موسمي |
| الاعتبارات | بيانات جوازات وسفر؛ وترخيص الخدمة الأساسية؛ ويجب أن تأتي دقة الإرشاد الديني والرسمي من مصادر معتمدة لا من النموذج |

## 4. التجزئة والتجارة الإلكترونية

| | |
|---|---|
| المشكلة | لا تستطيع المتاجر الإلكترونية الصغيرة الرد على كل رسالة عميل، فتخسر مبيعات بعد ساعات العمل |
| العملاء | متاجر المنصات المحلية للتجارة الإلكترونية، والبائعون عبر وسائل التواصل، والسلاسل الصغيرة |
| فرصة الوكيل | المبيعات والدعم عبر واتساب وقنوات التواصل الاجتماعي، وحالة الطلب، ومعالجة المرتجعات، وكتابة أوصاف المنتجات بالعربية، وتنبيهات إعادة التخزين |
| التعقيد | منخفض إلى متوسط. تتيح المنصات ومزودو الدفع واجهات برمجية |
| تحقيق الدخل | لكل محادثة تُحَل؛ ونسبة من المبيعات المستردة؛ واشتراك |
| الاعتبارات | أنظمة التجارة الإلكترونية وحماية المستهلك؛ وبيانات التواصل مع العملاء؛ وتحويل واضح إلى شخص |

## 5. الخدمات اللوجستية وتوصيل الميل الأخير

| | |
|---|---|
| المشكلة | يقضي منسقو التوزيع يومهم في توضيح العناوين ومعالجة استثناءات التسليم ومكالمات الحالة |
| العملاء | ناقلو الميل الأخير، ومشغلو الأساطيل، والتجار الذين لديهم توصيل خاص |
| فرصة الوكيل | تأكيد العناوين مع المستلمين، ومعالجة الاستثناءات، وإعادة الجدولة، وتحديثات الحالة الاستباقية، وإعداد مستندات الجمارك |
| التعقيد | متوسط. بيانات آنية وأطراف عدة |
| تحقيق الدخل | لكل شحنة تُعالَج؛ ولكل استثناء يُحَل |
| الاعتبارات | بيانات الموقع والتواصل؛ والتكامل مع أنظمة الناقلين؛ وصيغة العنوان الوطني |

## 6. العقار

| | |
|---|---|
| المشكلة | يجيب الوكلاء والوسطاء عن الأسئلة نفسها مراراً، ويصنّفون عملاء محتملين كثيرين لا يُتمّون صفقة |
| العملاء | مكاتب الوساطة، وفرق مبيعات المطورين، ومديرو العقارات |
| فرصة الوكيل | تأهيل العملاء المحتملين، ومطابقة العقارات، وجدولة المعاينات، وطلبات المستأجرين وفرز الصيانة لمديري العقارات |
| التعقيد | منخفض إلى متوسط |
| تحقيق الدخل | لكل عميل محتمل مؤهَّل؛ ولكل وحدة مُدارة شهرياً |
| الاعتبارات | الوساطة والإعلان نشاطان منظَّمان بمتطلبات ترخيص؛ وبيانات الهوية والبيانات المالية في عمليات الإيجار |

## 7. الخدمات المهنية

| | |
|---|---|
| المشكلة | تقضي شركات الاستشارات والمحاماة والتوظيف وقت كبار العاملين في البحث والمسودات الأولى والفرز |
| العملاء | شركات الاستشارات الصغيرة، ومكاتب المحاماة، ووكالات التوظيف، ومزودو التدريب |
| فرصة الوكيل | رصد المناقصات وطلبات العروض وتلخيصها، والمسودات الأولى للعروض، ودعم مراجعة المستندات، وفرز المرشحين وجدولة المقابلات |
| التعقيد | منخفض إلى متوسط للصياغة؛ ومرتفع حيث يكون الحكم المهني منظَّماً |
| تحقيق الدخل | لكل مستند؛ ولكل مناقصة تُتابَع؛ واشتراك |
| الاعتبارات | سرية العميل؛ وتبقى المسؤولية المهنية على المهني المرخَّص؛ والعدالة في فرز المرشحين |

## 8. التعليم والتدريب

| | |
|---|---|
| المشكلة | يتحمل مزودو التدريب والمدارس عبئاً إدارياً كبيراً: الاستفسارات، والتسجيل، والجدولة، والمتابعة |
| العملاء | معاهد التدريب، والمدارس الخاصة، ومراكز التقوية، والأكاديميات المؤسسية |
| فرصة الوكيل | معالجة التسجيل والاستفسارات، ومتابعة المتعلمين، ومساعدو التدرب والتدريس بالعربية، وتكييف المحتوى |
| التعقيد | منخفض إلى متوسط |
| تحقيق الدخل | لكل متعلم مسجَّل؛ واشتراك لكل مؤسسة |
| الاعتبارات | بيانات القاصرين تتطلب عناية خاصة وإشراك الأولياء؛ والدقة التعليمية |

## ملخصات أعمق للمقرر الأول

لستة قطاعات ملخص أطول للمتعلم (سير عمل للملاحظة، وأنظمة، ونقاط تماس تنظيمية، وسير عمل مرشح، وجهات مقابلة) في [`03-courses/01-opportunity/sector-briefs/`](../../03-courses/01-opportunity/sector-briefs/README.md): التجارة الإلكترونية، ومستندات الجمارك، والعيادات الخاصة، والوساطة العقارية، والمحاسبة، والموارد البشرية الخلفية. وتتبع القاعدة نفسها: فرضيات للاختبار، ولا معلومة رقمية دون مصدر.

## من الملخص إلى فرصة

1. اختر ملخصاً واحداً.
2. ابحث عن ثلاث منشآت في ذلك القطاع واطلب مراقبة سير العمل.
3. املأ الجزأين 3 و4 بما رأيته وسمعته.
4. قيّمها بـ[تقييم فرصة الذكاء الاصطناعي](../../04-entrepreneur-toolkit/02-ai-opportunity-assessment.md).
5. أعِد أدلتك إلى المستودع (بعد إخفاء الهويات) عبر طلب دمج ليبدأ المؤسس التالي متقدماً أكثر.
